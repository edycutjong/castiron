A self-healing audio-episode factory on Genblaze + Backblaze B2 — a cross-provider failover ladder, provenance sealed inside the MP3, and immutable Object-Locked publishing.

The problem

Generative pipelines are brittle at one point.

The vendor. One TTS 402 or outage mid-run and the whole episode dies — half-generated, nothing shipped, no record of what happened.

The solution

A ladder that catches the fall.

  • Failover ladder — narration steps ElevenLabs → LMNT → Hume until a rung answers. The episode lands.
  • Tamper-evident manifest — provenance is embedded inside the MP3 and hash-verified on read.
  • Immutable publish — the final episode is written to an Object-Locked B2 bucket (GOVERNANCE) — it can't be silently changed.

Sponsor integration — the SDK is the engine

Genblaze runs it. Backblaze B2 makes it permanent.

Genblaze — the pipeline
Real Pipeline.astream fan-out, a custom LadderTTSProvider over the provider interface, and read_manifest(verify=True) — the failover and provenance are SDK code paths, not glue.
Backblaze B2 — the vault
Object Lock (GOVERNANCE, 30d) for immutable episodes, Event Notifications → HMAC-verified webhook, and the S3 storage backend for the media store.
